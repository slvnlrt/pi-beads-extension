Show details for a Beads issue.

Guidelines:
- Use `$1` as the issue ID.
- If no issue ID is provided, ask for it.
- Verify Beads is initialized first.
- Prefer `bd show "$1"`.
- Summarize the important parts: title, status, priority, type, description, dependencies, and related follow-up actions.
- Do not mutate anything.
